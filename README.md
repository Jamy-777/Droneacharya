# Droneacharya

Droneacharya is a research-oriented multi modal UAV detection platform focused on passive RF and acoustic sensing.

## Current Status

Early research and development

## Initial Research Goals

- RF-based UAV detection and classification
- Acoustic UAV detection and classification
- Cross-dataset generalization
- Open-set / out-of-distribution generalization
- Multi-modal sensor fusion
- Real-time event detection and operator visualization

## Project Structure

- `src/` : application and signal processing source code
- `tests/` : automated tests
- `configs/` : project and experiment configuration
- `dataset_cards/` : dataset metadata and documentation
- `experiments/` : reproducible experiment definitions/results
- `notebooks/` : exploratory analysis
- `scripts/` : project utilities
- `docs/` : technical and research documentation

## Data

Large datasets are stored separately from the Git repository and are not committed to version control.
